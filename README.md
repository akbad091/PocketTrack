# 💰 PocketTrack – Expense Tracker

A simple, modern, and responsive expense tracker built with **HTML, Tailwind CSS, and Vanilla JavaScript**.

PocketTrack helps users manage their personal finances by tracking income and expenses, organizing transactions, and viewing their financial summary.

## ✨ Features

- **Dashboard:** View total balance, income, and expenses.
- **Add Transactions:** Record new income or expenses.
- **Delete Transactions:** Remove existing transactions.
- **Categories:** Organize transactions into Food, Transport, Shopping, Entertainment, and Other.
- **Transaction History:** View recorded transactions.
- **Filter Transactions:** Filter transactions by category.
- **Responsive Design:** Adapted for desktop and mobile screens.

## 🛠️ Technologies

- HTML5
- Tailwind CSS v4 (Play CDN)
- Vanilla JavaScript
- DOM Manipulation

## 🎨 Design

PocketTrack follows a clean, modern, and minimal finance dashboard design.

- **Primary Color:** Indigo
- **Typography:** Inter & Urbanist
- **Style:** Minimal, clean, and responsive

## 🚀 Getting Started

No installation or build process is required.

1. Clone the repository:

```bash
git clone https://github.com/akbad091/PocketTrack.git
```

2. Navigate to the project folder:

```bash
cd PocketTrack
```

3. Open `index.html` in your browser.

Alternatively, use the **Live Server** extension in VS Code for a better development experience.

> **Note:** PocketTrack uses the Tailwind CSS Play CDN, which requires an internet connection. The Play CDN is intended for development and learning, not production deployment.
